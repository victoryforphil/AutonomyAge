# vs-wtf

The Victory Suite time library.

A very-skilled engineer once gave me solid advice to "never make your own time
library" and to "just use the native ones". This is solid advice. Do this.

Anyways, heres my own time library :)

Provides `Timepoint`, `Timespan`, and `Timecode` primitives with lossless
conversions between unit scales. Part of the [Victory Suite](../) workspace
(under `libs/`).
