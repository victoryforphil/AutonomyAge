# vs_appkit (Idea)

- EGUI based helper / component / framework crate for building desktop apps
- Reusable widgets, components, and app scaffolding that sit on top of `egui`
- Opinionated but composable: small pieces you opt into rather than a monolithic UI layer
- Source material: desktop-app UI code from around VictoryForPhil/AndreasLabs, import from there
- Could layer on top of `vs-wtf`, `vs-data-store`, and `vs-broker` for live-visible state in tooling
