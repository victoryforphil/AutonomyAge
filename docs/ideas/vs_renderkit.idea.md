# vs_renderkit (Idea)

- 3D rendering kit: scene, shader, mesh, and graphics helpers built on `three-d`
- Reusable rendering components/helpers for building and rendering 3D scenes cleanly
- Works in several embed contexts: inside `egui`, in standalone apps, or headless
- Designed like `vs_appkit` but for 3D: composable components you opt into rather than a monolith
- Source material: sources behind victory-appkit and other 3D rendering code around VictoryForPhil/AndreasLabs, consolidate from there
- Could pair with `vs-viz` for visualization and `vs_appkit` for desktop app shelling
